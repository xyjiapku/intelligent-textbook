# Game Theory Rush · 博弈论教学网页（离线便携版）

## 怎么用

**最简单**：双击 `index.html`，用浏览器打开即可。无需安装、无需联网、无需服务器。

**推荐**（更稳，尤其是要让两个交互小程序正常嵌入时）：在本文件夹下起一个本地静态服务，再访问 `http://127.0.0.1:8000/`。

```bash
# 装了 Python 的话，在本文件夹里执行：
python -m http.server 8000
```

> 为什么要用服务：浏览器对 `file://` 下的内嵌页面有安全限制，少数浏览器/设置下 iframe 会加载不出来。
> 即使加载失败也不会卡住——页面会给出提示，点「在新窗口打开 ↗」照样能用。

## 目录结构

```
GameTheoryRush-Portable/
├─ index.html                        教学网页本体（三章 / 8 个交互矩阵 / 20 个讲解器）
├─ mini-lab/                         经济学互动实验室的两个小程序
│   ├─ Nash-Eq Quantity Game.html    古诺双数量竞争（反应函数 / 纳什均衡）
│   ├─ Nash-Eq Location game.html    霍特林位置竞争（选址 / 市场份额）
│   ├─ theme.css / theme.js          站点主题（已本地化，消除 404）
│   └─ favicon.ico
└─ vendor/katex/                     数学公式引擎（已本地化，离线可用）
    ├─ katex.min.css / katex.min.js
    └─ fonts/*.woff2                 20 个字体文件
```

## 离线可用性

| 功能 | 离线状态 |
|---|---|
| 三章正文、双语术语、思考-揭示、课后习题 | ✅ 完全可用（全部内嵌） |
| 8 个博弈矩阵（最佳回应 / IDSDS 双方法逐步求解） | ✅ 完全可用（原生 JS） |
| 数学公式（KaTeX 渲染） | ✅ 完全可用（已本地化，含字体） |
| 两个交互小程序 | ✅ 完全可用（已本地化，无外部依赖） |
| 字体（Noto Serif SC / Inter / JetBrains Mono） | ⚠️ 在线时加载网页字体；离线时自动回落到系统中文字体（宋体/苹方等），排版略变但完全可读 |
| 「信任的进化」外链卡片 | ℹ️ 需联网才能打开（外站链接，属正常） |

## 搬运到别处

整个文件夹拷走即可，可以放到 U 盘、别的电脑、任意静态服务器、或压缩包分发。
**注意**：如果只拷贝 `index.html` 一个文件，正文和公式没问题，但两个交互小程序会缺失（它们在同目录的 `mini-lab/` 里）。

## 与源项目同步
